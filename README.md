# plink-fall

同一个项目提供两种独立游戏模式

- `/`：原弹珠挂机游戏
- `/?type=codex-forge`：月背工坊，轻点操作的自动采集与构筑游戏

## 本地启动

使用 Node.js 24，首次安装依赖后启动 Vite

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5198 --strictPort
```

打开 `http://127.0.0.1:5198/?type=codex-forge` 体验新模式，去掉 query 体验原模式

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 5199 --strictPort
npm run lint
```

## 月背工坊

开动工坊后，矿石自动经过熔炼、冷凝，变成结晶。装满订单后亲自交付，获得晶币、蓝图和一次模块选择。第一单约 17 秒完成，共振可以提前装满

- 八种模块各三级：采矿、产量、分流、价值、共振和冷却有不同取舍；安装后机器和物料流实时变化
- 第一单开放模块，第二单开放永久研究和结晶收藏，当前旅程交付四单后可以跃迁
- 三种月海和结晶随旅程探索；跃迁重新构筑产线，研究、晶币、蓝图和收藏保留
- 共振充能后可短时加速，偶尔出现的矿星可以轻点拾取；不要求拖拽或连续点击
- 离线按产线收益的 50% 结算，最多四小时；主动暂停不产出，订单和选择留待玩家回来操作

进度保存在当前浏览器，新模式使用 `codex-forge-save-v1`，原模式使用 `plink-fall-save-v1`。清除浏览器数据或更换设备不会同步进度

## 结构与验证

`src/forge/model` 管理模拟、选择和存档；`render` 管理 Pixi 场景与实际物料；`ui` 管理渐进解锁和 React 面板。入口动态加载各自模式，开发模式才加载测试接口

已验证逻辑长时间循环、研究扣费、暂停、跃迁、离线和异常存档；浏览器实玩覆盖首单、模块、研究、矿星、保存恢复及原模式回归。360/390/414 像素竖屏与 844×390 横屏已检查，真实 iOS 设备性能和音频许可尚未测试
