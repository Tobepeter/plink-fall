# plink-fall

同一个项目提供独立游戏模式

- `/`：原弹珠挂机游戏
- `/?type=codex-forge`：零点突围，自动射击、移动躲弹、冲刺切弹的全屏动作肉鸽
- `/?type=codex-rush`：零点突围的独立入口，便于比较
- `/?type=codex-mine`：保留上一版矿脉回声

## 本地启动

使用 Node.js 24 和 pnpm 10.32.1

```sh
pnpm install --frozen-lockfile
pnpm dev
```

开发服务默认使用 `127.0.0.1:5198`，打开 `http://127.0.0.1:5198/?type=codex-forge`。端口被占用时明确报错，不会自动换端口

```sh
pnpm build
pnpm preview --host 127.0.0.1 --port 5199 --strictPort
pnpm lint
```

## 零点突围

首次进入显示机体磁环装配动画，真实资源就绪后自动开打；浏览器记录首访，再次进入时先到整备舱，点击“开始突围”手动出击。PC用 WASD/方向键移动，默认自动索敌并持续开火，空格/右键冲刺，E发动角色技能；整备或暂停时可开启鼠标方向瞄准，开关自动保存。触屏按住空地轻推方向并自动瞄准，右下有冲刺与技能，不显示鼠标开关。鼠标拖动不会移动角色。冲刺提供短无敌并清掉路径附近的敌弹；一次截获至少三发，结束会自动释放穿透反击。受击后有短保护时间

整备首页只显示当前机体、大开始按钮、难度入口，以及机体/强化/战绩三个图形入口。换机体、永久强化、难度、战绩和设置各自进入独立二级画面，返回或 Escape 回到首页并恢复入口焦点；首页不滚动。未解锁机体可以免费预览，明确购买后再选用；金币只在实际解锁或强化成功时扣除

竞技场为有限1920×1440封锁区，人物、冲刺、敌人和掉落都不能越界。边缘有实体围墙、斜纹护栏和角灯，右上雷达显示真实场地位置，暂停按钮在其下方，左下留给移动操作；镜头到边缘停下，并在有限的护栏外视觉带保留角色完整轮廓。普通弹射弹能消耗弹射次数反弹墙，其他出界弹丸及时回收

击败追兵获取经验，达到门槛时底部出现三枚技能装配选项，战斗继续。沙漏显示8秒倒计时，标出固定推荐：优先补齐已有组合，再考虑机体和已学技能。可提前点击图标或PC按1/2/3选其他项，到期自动接入推荐；手动和超时同样真实扣经验并升级一次，不清空移动输入。待选时积累的经验保留，下一次供选在提交7秒后；暂停、后台冻结倒数，跨波不会重置。弹射、电链、环刃、散射、穿透、追踪火箭、伴飞炮、冰径、震荡环、极速扳机、修复甲和引力核共十二种，均有实际攻击或避险效果，每种最多五级。连杀和擦弹积累角色身边的充能弧，充满自动进入三秒超载，射速提高并散射

待选装配只保留军械图、短名、等级槽和倒计时，完整效果保留在可访问标签与悬停说明；推荐项有装配图标和2.2秒呼吸光，文字和点击区域保持静止，减少动态效果模式保留静态亮边。触屏第二指按下即可选装、发动技能或冲刺，第一指仍控制移动；竖屏待选区位于右下操作键上方，横屏重新分配区域。声音设置放在主动暂停中，暂停期间战场和后方控件不可交互，继续后键盘焦点回到战场

金币、时间、击杀、等级与菜单入口共用生成的透明游戏图集，保持军械的描边与薄荷绿/黄铜配色。结算突出金币奖励、三个图标指标和返回整备/再战，收益明细收进战绩页主动展开

装备配对自动接入三种协议：环刃＋电链形成电磁回路，环刃命中连锁电击；冰径＋火箭触发霜爆，炸裂冰场中的冻结目标；弹射＋散射形成折返弹幕，冲刺召回飞行中的散射弹穿过敌人。装配界面会提示已有模块的搭配

九波分成三个阶段，每个阶段以 Boss 封锁结束，HUD保留波次、当前波倒数、九段进度和等级经验，波名只在开波短暂提示。普通波使用有限编队、错峰夹击和逐步增加的弹幕；过波只清理旧敌人与敌弹，0.6秒后自动接上下一波。移动、冲刺、技能、己方弹道与经验拾取连续运行，波次不会弹出界面、强制选装、加经验或自动修复。局内武器升级只由击杀掉落的经验触发，与波次独立。Boss波需要真正击破封锁才推进，三次封锁完成突围

疾行者从弹射起手，E发动2.5秒三路齐射并提高射速，单发主炮伤害稍低；守卫从环刃起手，E发动近身震击和1.2秒无敌，移速和主炮伤害较低；闪电从电链起手，E发动最多六目标电链爆发，移动更快、装甲只有3格。经验选装偏向所选机体与已学技能，可进一步接入组合协议。守卫/闪电分别可花36/60金币提前解锁，也能通过首Boss/通关免费解锁

封锁难度0～3星逐级通关解锁，星级增加敌人生命、编队、移速、弹数/弹速与攻击频率，金币收益分别×1/×1.25/×1.5/×1.8。角色、星级、瞄准设置与战绩持久保存，当前局难度开局后固定

每次结束至少带回12金币，击杀、完成波次、Boss与通关追加奖励。整备舱可以购买高能弹芯、强化装甲、极速电容和回收线圈，永久提高下一局的伤害、初始装甲、射击/冲刺冷却或经验吸附范围。金币与强化自动保存，重复结算或重载不重复领取；第一败就能购买首级火力或线圈

保存金币、永久强化、星级、机体、瞄准设置、最好纪录与声音偏好，不保存进行中的短局，也没有离线收入。旧版默认开启的鼠标设置首次迁移为关闭；新版手动开启后继续保存。整备菜单停止战斗RAF/物理/声音；Escape 或右上可主动暂停，页面切到后台停止战斗与声音，回来继续当前进度。连续过波和经验待选保留方向键与触屏捕获，不停止战斗帧循环或音乐

`codex-rush-save-v1` 与旧采矿 `codex-mine-save-v1`、旧工坊 `codex-forge-save-v1`、原弹珠 `plink-fall-save-v1` 分别保留。清除浏览器数据或更换设备不会同步进度

## 历史采矿模式

点矿脉出钻，接触矿壳后持续钻探；长按再松开能释放共鸣，击碎身边矿体。碎矿弹跳、吸附到探针，并形成有负重的随行货物。再点空地或点“收缆”回库，满载和过热也会自动返航

桌面支持方向键瞄准、空格短按出钻或收缆、空格长按共鸣、R 收缆、Escape 暂停。无需拖拽，桌面与移动端均直接使用完整视口

- 首箱 5 件，普通出钻约 11 秒回库；随后选择穿岩、连锁或拾矿帆，工具会改变碰撞、邻矿损伤或实际运回的载荷
- 共八种工具，每种三级；第二次回库开放巡采和永久改装，巡采开启后空闲 9 秒再出钻，手动操作能接管
- 三种矿区具有不同矿种比例、硬度、价值和危险矿；完成三次里程碑后揭露遗物，亲自运回才能带着永久设备前往下一矿区
- 长缆轴、散热、矿袋各五级，换区保留；局内工具重新构筑
- 离线最多四小时，只补充晶币；主动暂停无收益，离线不会代替玩家领取工具或运回遗物

进度保存在当前浏览器。采矿模式使用 `codex-mine-save-v1`，旧工坊存档 `codex-forge-save-v1` 和原弹珠存档 `plink-fall-save-v1` 分别保留。清除浏览器数据或更换设备不会同步进度

## 结构

`src/rush/model` 负责真实敌人、弹道、碰撞、武器、局内/局外成长和纪录；`render` 负责 Pixi 场景、镜头和动作反馈；`ui` 负责 HUD、装配、整备和结算。运行时统一管理输入、声音、DPR 和后台恢复；各模式按入口动态加载，开发调试接口不进入正式构建

步态由实际移动距离驱动，起步/落脚/收步连续衔接，冲刺使用独立姿势。短装配、奖励吸收、反击与超载动效使用 Tween.js 25 的单一 Group，由游戏有效帧时钟推进；主动暂停和后台停止推进，经验待选期间继续，完成/停止时移除，重开与卸载清理全部实例。DOM 加载/按钮/呼吸反馈由随组件生命周期结束的 CSS 动画呈现，尊重 reduced-motion

旧 `src/mine`、`src/forge` 保留历史实现。任务文档、一手设计研究、素材提示词、实玩录像和验证脚本集中在本地 `.temp/tasks/plink-fall/`，该目录不提交到 Git。后台验证使用隔离浏览器，任何真实操作前关闭游戏音频并读取静音状态，录屏与自动化同样静音

浏览器验证使用 Chromium 模拟桌面及手机尺寸，不代表真实 iOS 设备性能或玩家的主观体验
